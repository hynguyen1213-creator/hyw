# G.LENS Pro — iPhone camera

Native SwiftUI / AVFoundation camera for iOS 17+, with manual exposure, focus and white balance; RGB histogram, zebra and peaking; JPEG/HEIF and supported RAW; photo sequences; video, slow motion and time-lapse; on-device looks and a local gallery.

See [features, limits and device checks](PRO_FEATURES_VI.md) in Vietnamese. [Build and signing instructions](README_VI.md).

GitHub Actions compiles a real ARM64 IPA. Unsigned artifacts require a valid signature and provisioning profile before installation. This project is independent of Leica and Xiaomi and does not reproduce their proprietary processing or hardware.
